## Projetos em destaque

### Sistema de Gerenciamento de Inspeções

Aplicação desenvolvida para auxiliar os processos operacionais de uma empresa de inspeções de risco para seguros.

**Principais funcionalidades:**
- Distribuição e gerenciamento de inspeções.
- Organização das atividades dos inspetores.
- Aplicativo mobile para execução das vistorias.
- Captura e organização de fotografias.
- Automação do processo de identificação e renomeação de imagens.

**Tecnologias:** JavaScript, React Native e Expo.

### Sistema ERP para Pequenas Empresas

Projeto desenvolvido como Trabalho de Conclusão de Curso (TCC), utilizando Python, com foco na gestão empresarial e organização de processos.

O projeto proporcionou contato com conceitos de sistemas de gestão, desenvolvimento de funcionalidades e resolução de necessidades administrativas.

**Tecnologia principal:** Python.

### Flyppo — Plataforma de Estudos com Flashcards

Aplicação web desenvolvida para auxiliar na organização dos estudos por meio de flashcards e repetição espaçada.

**Principais funcionalidades:**
- Organização de conteúdos por matérias e assuntos.
- Diferentes formatos de cartões de estudo.
- Sistema de repetição espaçada.
- Estatísticas de desempenho.
- Sincronização de dados em nuvem.
- Funcionamento offline.
- Interface com temas claro e escuro.

**Tecnologias:** HTML, CSS, JavaScript, Supabase, PostgreSQL e IndexedDB.
